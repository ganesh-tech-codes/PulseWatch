⚡ PulseWatch

Real-Time Monitoring Dashboard

PulseWatch is a web-based dashboard project designed to present monitoring information through a clean, organized and user-friendly interface.

📌 Project Overview

PulseWatch aims to provide a centralized dashboard experience where users can view and monitor important information in one place.

The project focuses on a modern interface, organized components and a responsive user experience.

🚀 Getting Started

Follow these steps to run PulseWatch locally.

1. Clone the repository

git clone https://github.com/ganesh-tech-codes/PulseWatch.git

2. Navigate to the project

cd PulseWatch

3. Install dependencies

npm install

4. Start the development server

npm run dev

Open the local URL displayed in your terminal.
